## 截图验收要求

- 使用外部 Chrome 或 Edge，不使用概念图；
- 记录浏览器视口、缩放比例和测试图片；
- 截图不得出现 AK、SK、access token 或带签名的上游结果 URL；
- 成功态必须来自真实计费任务，mock 成功态只能作为补充，不能替代；
- 如果真实任务失败，保留失败截图并记录请求阶段、错误分类和是否返还额度。

## 本版 UI 边界

- 当前可见变化仅发生在没有模型时的图生模型入口；
- `/api/split` 是本版完成的后端能力，工作台“自动拆件”按钮与结果导入将在 M1.13b 实现；
- 因此本版不伪造拆件面板截图，也不把后端接口描述为用户已可直接完成的拆件流程。
