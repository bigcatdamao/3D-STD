## UI 设计变化

- 信息架构：手动切割与云端自动拆件成为两个明确入口；
- 控件：增加低/标准/高三档粒度，标准档默认推荐；
- 决策信息：提交前同时展示面数、临时文件大小、20 Credits 与外部处理说明；
- 状态：提交、排队、运行、下载解析、完成、失败六类反馈在同一右侧面板内连续呈现；
- 安全反馈：明确原始资产保留、等待期间不编辑源模型、失败时不修改场景；
- 下一步边界：面板底部明确榫卯、公差和装配验证不属于本次自动拆件。
