## 页面证据

1. `01-overview.png`
   - 用户选中连接测试件 A；
   - 顶部 `＋ 添加连接` 入口变为可用，普通属性栏仍保留；
   - 证明功能入口遵守“只选一个零件才亮起”的规则。
2. `02-entry.png`
   - 用户点击连接入口，右栏变为三步式连接面板；
   - 系统要求先在 A 零件表面点击连接中心；
   - 证明连接器不是常驻大弹窗，不会遮挡主要 3D 画布。
3. `03-interaction.png`
   - A/B 两个相向点已经确定，画布出现候选点、方向箭头和连接线；
   - 右栏显示凸榫/凹槽角色、直径、插入深度和总间隙；
   - 证明定位、配对和参数决策集中在同一操作上下文。
4. `04-result.png`
   - 用户完成预览并确认，场景显示两个真实布尔后的独立零件；
   - 历史栏只有一条 `添加连接` 操作；
   - 证明双零件修改是一个原子操作，但不等于已经完成真实打印与装配公差验收。

## 信息架构与状态

- 入口放在“手动拆件 / 自动拆件”附近，后续可以一起收纳进制造工具栏；
- 右栏始终只显示当前步骤需要的信息：选 A、选 B、调参数 / 确认；
- 画布负责空间定位、方向反馈和预览，右栏负责离散决策和精确数值；
- 预览态明确说明“尚未修改模型”，确认态才创建派生资产；
- 退出、失效、布尔失败和超面数都保留明确错误状态，不静默生成假结果。
