## 本版 UI 变化

- 自动拆件面板版本标识更新为 M1.17a；
- 混元生成资产显示“混元组件生成”，本地或旧供应商资产显示“Hi3D 自动拆件”；
- 混元面板显示“原始混元 FBX”和 30 Credits；
- 混元模式移除无效的粒度按钮，并明确当前接口会按结构生成独立 GLB；
- 提交前说明改为复用供应商侧 FBX，结果返回后才建立独立零件；
- Hi3D 原有 STL 上传与粒度控件保留，作为回滚/本地模型路径。

## 截图验收要求

- 浏览器 100% 缩放，优先记录 1920×1080，并补一张 1366×768 可用性检查；
- 隐藏账号、密钥、私有文件名和供应商临时 URL；
- 至少一张图能同时看到模型、M1.17a 标识、费用说明和主 CTA；
- 成功态必须看到两个以上可独立选择的零件；
- 若真实生产仍失败，`04-result.png` 可记录失败态，但 README 必须写明上游错误码、是否生成任务 ID、是否退款和故障阶段。

## 当前体验结论

本版优先解决供应商闭环和真实能力表达，没有重做主工作台。相比 M1.16b，用户能知道当前由谁生成、为何需要二次付费、结果会以什么形式进入场景，也不会被不存在的混元拆件粒度设置误导。完整对话到打印准备的体验与 UI 收敛放在 M1.17b。
