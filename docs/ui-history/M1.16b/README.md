## 信息架构与交互变化

- 对话仍在左栏，但模型每轮最多展示一个关键问题；
- 快捷选项是可选回复，不再要求填完一组表单后提交；
- 用户可以直接自由输入，或点击“交给 Agent 决定”；
- 右栏 CTA 从两步改为“确认 Brief 并生成视觉方案”；
- 方案选择后的 CTA 明确写出“确认方案并生成效果图 · 1 次”，不隐藏费用动作；
- 中栏继续保持固定画布，不因从需求、方案、效果图切换而改变窗口尺寸。

## 2026-08-02 实测诊断

- 本地 Vite 的 `/api` 默认代理到 `https://3d-std.851241233.workers.dev`；
- 线上静态包仍是 M1.15a，不含 M1.16b、`deepseek-v4-flash`、单问题交互或新视觉方案链路；
