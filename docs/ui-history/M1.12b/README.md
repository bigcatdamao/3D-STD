### 05-cap-warp-failure.png

- 用户状态：在可见前表面画出 6 段闭环并生成预览；
- 系统反馈：接缝封口扭曲率为 14.5%，超过当前 12% 安全阈值，真实 A/B 被拒绝；
- 证明内容：绘制闭环不等于已经定义了可封口的实体拆分面。当前内核适用于近似平面的环切，
  不能把任意表面套索直接解释成有厚度的拆件体；
- 体验问题：计算失败后程序自动把路径重新标记为“开放”，容易让用户误以为黄色起点没有点中；
- SHA-256：`0A6F8527781FEEB710194D63F8B9DFAEDDD7B1C26BA8343EB9E6131294ECAB97`。

## UI 与体验变化

- “贴面切割笔”升级为“多视角切割笔”；
- 支持单击放置锚点与按住拖动自由绘制，两种方式可混用；
- 松开鼠标只暂停，不再自动用直线闭合；
- 用户可右键旋转到侧面或背面，再从青色末端续画；
- 黄色起点是唯一显式闭合入口；
- 开放路径显示段数、点击段、自由绘制段和首尾距离；
- 闭合前主按钮显示“等待闭合切口”，避免误以为已经形成可切割闭环；
- `Ctrl+Z` 先撤销闭合，再逐段撤销笔迹；
- 右侧保留 M1.11g 面组实验入口，旧方案未删除。

## 截图验收注意

- 截图必须来自实际本地页面；
- 至少一张包含完整右侧交互面板；
- 至少一张清楚显示黄色起点与青色末端；
- 高面数模型截图须保留“高面数预览待接入”，不能把绘制体验表述成真实切割已经完成；
- 截图时发现端点标签外层会拦截鼠标，已将两个 `Html` 标签的外层设为
  `pointer-events: none`，真实页面重新验证后黄色起点可点击闭合。
