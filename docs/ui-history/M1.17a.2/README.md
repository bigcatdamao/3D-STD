前四张截图只证明入口与布局；后两张是用户后续补充的真实混元付费拆件证据。它们证明链路可以成功返回 19 个零件，但不证明所有题材都能稳定拆件，也不证明拆件边界和细节质量已经达到商业可用。自动拆件仍只对带混元 `hy3d_` 来源的生成资产开放；本地导入模型继续使用手动拆件。
