## 体验结论

- 参考图不再藏在底部旧生图入口，而是进入 Agent 的需求理解区；
- 用户可以不上传图片，继续纯对话；也可以添加 1–3 张图片并单独触发 VLM；
- 页面在初始状态明确区分“理解参考图”和后续付费生图；
- 1366×768 下没有遮挡参考图按钮、输入框和 Brief 确认按钮；
- 生产 VLM 和效果图 API 已实调通过；效果图、三视图与 Hi3D 交接的用户操作状态仍需在下一轮体验测试中补图，不能用静态假数据冒充。
