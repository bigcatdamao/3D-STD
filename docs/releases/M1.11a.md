## 本版目标

M1.11a 只回答一个问题：用户能否像在模型表面涂画一样，直观、流畅地表达“这部分以后要拆下来”。

本版不把面组转换成真实接缝，也不执行 A/B 切割。M1.10b 的真实曲面切割底层继续保留，但不从当前 UI 触发，避免把尚未验证的几何能力包装成完成态。

## 产品与交互

- “✂ 拆件”默认进入“绘制面组”；“平面切割”仍保留为第二页签。
- 左键连续添加紫色面组；`Ctrl+左键` 临时擦除。
- `B` 切换添加、`X` 切换擦除；右栏滑块和 `[` / `]` 调整画笔半径。
- 鼠标悬停显示贴合命中面的圆形画笔；松手后黄色面组边界立即更新。
- 一次连续拖动合并为一笔；`Ctrl+Z` 或“撤销上一笔”整笔恢复。
- “清空面组”也写入面组自己的临时撤销栈，不污染场景历史。
- 右键旋转、中键平移、滚轮缩放继续使用原相机映射；这些操作不会新增笔划或误涂。
- 主按钮明确显示“下一阶段：生成接缝”且禁用，避免用户误以为当前已经能执行曲面切割。

## 实现

- 新增 `face-paint-state.ts`：`Uint8Array` 面掩码、本地笔划栈、添加/擦除、半径和低频统计。
- 新增 `face-paint-core.ts`：画笔样本应用、同一连续表面筛选、焊接边拓扑和面组边界提取。
- 新增 `ManualFacePaintEditor.tsx`：canvas 原生指针事件、RAF 合帧、BVH 射线/范围查询、GPU 顶点色覆盖、画笔圆环与边界线。
- 高频 pointermove 不写 Zustand；松手后才发布 `maskRevision` 和统计。
- BVH 球形候选会再从真实命中面按共享边扩散，并用法线方向过滤，避免薄模型背面和空间邻近但不连通的表面误染。
- BVH 会重排三角面；拾取、覆盖层和边界统一从重排后的同一几何创建，确保面索引一致。
- 右/中键按下时跳过画笔 hover 射线，减少转相机时的额外工作。

## 性能与降级

- 画笔采样使用 BVH，不再对整模型逐面扫描。
- 指针移动每个动画帧最多执行一次采样。
- 100,000 面以内在每笔结束时构建/复用焊接边拓扑并显示黄色边界。
- 超过 100,000 面自动进入“高面数流畅模式”：继续实时显示紫色面组，但不单独构建黄色边界。
- BVH 在工具首次打开时同步建立；超高面数模型仍可能有一次性的进入等待，后续可评估 Worker 构建或持久缓存。

## 当前能力边界

- 面组只存在于当前会话；退出、刷新或切换新对象后清空，不写项目文件。
- 紫色区域按源三角面着色；低面模型会呈现明显的多边形边缘，高面模型更接近连续画笔。
- 当前半径按世界毫米近似换算；实例存在强非等比缩放时，画笔在局部空间可能略呈椭圆。
- 黄色边界只是面组区域边界，不是经过几何验证的可切割接缝。
- 尚未处理多面组命名、隐藏面遮挡涂画、穿透涂画、对称涂画或套索填充。
- 不包含真实曲面拆分、局部重网格、封口、榫卯、公差、装配验证或 Agent 写权限。
