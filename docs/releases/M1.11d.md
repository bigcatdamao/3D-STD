## 产品边界

- 平面切割继续负责躯干、腿部、武器和机甲大结构等大范围分割。
- 绘制面组改为“关节局部模式”，用于脖子、肩甲、手腕、膝盖、鞋口和装甲接缝。
- 不尝试为整张百万面模型构建全局邻接图；紫色面组已经明确 A/B，不再运行全局最小割。

## 本版实现

- 实时涂画仍只更新紫色覆盖层，超过 100,000 面时不在主线程持续重建黄色边界。
- 高面数状态下“分析局部接缝”保持可用；点击后由独立 Worker 扫描紫色关节区域及其直接邻边。
- 局部拓扑的内存规模随已涂关节面组增长，而不是随整张模型的全部边增长。
- 接缝 Worker 提供进度、60 秒超时、取消和失败回退；分析期间不允许继续修改面组。
- 真实 A/B 生成增加独立的面组快速路径：只验证局部接缝，随后线性遍历源三角面并输出两件。
- 旧版自动曲面寻路继续保留 80,000 面预算，避免改变其性能与失败边界。

## 首版预算

| 项目 | M1.11d 目标 |
|---|---:|
| 模型总面数 | 2,000,000 面以内 |
| 紫色局部面组 | 250,000 面以内 |
| 局部接缝边 | 12,000 条以内 |
| 封口轮廓顶点 | 12,000 点以内 |
| 后台超时 | 60 秒 |

这些数值是首版防护预算，不代表所有满足面数的网格都一定可切。开放边、非流形、分叉、多环、自交或封口扭曲仍会 fail-closed。

## UI 调整

- 面组统计改为“模型总面 / 已涂面 / 局部接缝”。
- 高面数提示改为“高面数 · 关节局部模式”，不再要求用户先减面。
- 高面数主按钮改为“分析局部接缝”，分析中显示后台阶段并禁用重复提交。
- Worker 失败与预算超限显示明确原因；源模型和当前紫色面组保持不变。

## 验收重点

1. 导入 10 万面以上手办或机甲模型并进入绘制面组；
2. 确认紫色涂画、擦除、画笔撤销和视图操作仍然流畅；
3. 在单个关节附近涂出一个区域，点击“分析局部接缝”；
4. 确认出现绿色单闭环，且模型总面数不会直接禁用按钮；
5. 生成真实 A/B 预览，确认两个临时零件和封口指标；
6. 返回接缝时不修改场景，确认创建后可用一条历史撤销；
7. 使用超过 25 万面的紫色区域、多个闭环或开放网格验证 fail-closed。
