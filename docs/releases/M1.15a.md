## 用户价值

用户不再只能靠文字描述。Agent 可以理解 1–3 张本地参考图，把图像证据补入可编辑 Brief；确认文字方向后，再由用户明确触发效果图或三视图生成，检查视觉结果后交给已有 Hi3D 单图/多图成模流程。

## 本版链路

1. 自然语言对话整理 Brief；
2. 可选添加 1–3 张参考图，浏览器缩放压缩后交给 VLM；
3. VLM 只补充 Brief 中原本为空的主体、类型、风格和姿态，保留用户已填写内容；
4. 用户确认 Brief，LLM 返回三套可比较视觉方向；
5. 用户选择并确认方案；
6. 用户点击后才调用 `gpt-image-2` 生成低质量效果图；
7. 可直接用效果图进入 Hi3D 单图成模，或再生成三视图参考表；
8. 三视图表在浏览器切成正面、左侧、右侧三张文件，交给现有 Hi3D 多图流程；
9. Hi3D 仍保留自己的提交确认、Turnstile、配额、轮询、失败退款和结果接受；
10. 接受模型后继续复用现有编辑、手动/自动拆件、打印检查、确定性修复和 STL 导出。

## 模型与服务边界

- AIHubMix Key 已真实验证：`gpt-5.6-sol` 结构化 LLM、`gemini-2.5-flash` VLM、`gpt-image-2` Images API；
- `gpt-image-2-free` 当前实测无可用 channel，生产默认不依赖免费通道；
- 同一 AIHubMix Key 不替代 Hi3D Key；3D 成模与自动拆件继续使用 Hi3D 服务；
- 模型列表可见不等于通道始终可用，生产验收必须逐端点实调；
- 生成三视图是视觉一致性辅助，不是工程正投影保证；3D 后仍需检查背面、比例和连接关系。

## 安全与费用

- Key 仅存在于 Cloudflare Worker Secret，不进入前端、Git、浏览器响应或日志；
- 参考图先在浏览器压到最长边 1024px、JPEG 0.82，再上传给 VLM；原图和 base64 不写 localStorage；
- VLM、生图和 Hi3D 使用三个独立配额域；上游失败均退款；
- 生图使用 `1024×1024 + low quality + n=1` 控制首版成本；
- 生图与 Hi3D 是两次独立点击，不能由一次总授权自动连续扣费。

## 明确不包含

- 不承诺生成的三视图严格正交或跨视角几何完全一致；
- 不把视觉参考图评分当作网格检查；
- 不自动执行拆件、修复、连接件或导出；
- 榫卯、公差、装配验证和直接发送打印机仍未实现，不能在 Agent 中伪装成可用工具；
- 产品终点仍是导出打印就绪 STL 并交接 Bambu Studio 等切片软件。
