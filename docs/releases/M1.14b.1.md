## 用户问题与判断

生产截图显示两条 LLM 链路都发生了安全降级：对话消息标记“本地引导 · 未调用大模型”，三套视觉方案请求失败并返还额度。该现象不是用户输入或操作错误，而是第三方兼容接口未接受本轮结构化输出请求。

第一轮根据原有通用 502 现象，把两份输出 Schema 收敛到更保守的 JSON Schema 子集，同时为服务端增加不泄露响应正文的状态码和机器错误码诊断。更换 Key 后，本地直连成功而 Cloudflare Worker 访问站点主域仍返回 401；把 AIHubMix 端点切换到专用 API 主机 `api.aihubmix.com` 后，生产对话与三方案均恢复。Schema 兼容改进与安全诊断继续保留。

## 修改内容

- 移除请求 Schema 顶层 `$schema`；
- 用单值 `enum` 替代 `const`；
- 移除不影响运行时校验的字符串长度约束；
- 使用 `type: [T, "null"]` 表达可空字段；
- 保留根对象、必填字段和 `additionalProperties: false` 的严格输出边界；
- 对第三方失败只提取 HTTP 状态、`error.code` 和 `error.type`，不记录响应正文；
- 区分结构不兼容、授权失败、限流、超时与一般服务失败；
- 所有失败仍返还本轮应用内额度，且不生成本地假方案；
- 页面版本标识升级为 `M1.14b.1`。

## 安全边界

- API Key 仍仅从 Cloudflare Secret 读取；
- 前端、Git、日志和浏览器响应均不返回密钥；
- 不透传第三方错误正文，避免服务商信息、请求内容或敏感字段进入日志；
- 生产验证只检查状态、Provider、模型与结构数量，不输出用户内容或完整模型响应。
