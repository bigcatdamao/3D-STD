## 真实故障

用户在 M1.17a 生产环境完成 Agent 对话和效果图确认，点击“生成模型”后，页面返回：

`Illegal invocation: function called with incorrect 'this' reference`

错误发生在腾讯云任务成功创建之前，因此没有混元 JobId。站内本次扣减已按 AI-07 返还；从当前证据看，请求没有形成可计费的腾讯云生成任务。

## 根因

`worker/tencent-cloud-client.ts` 将 Cloudflare Workers 的全局 `fetch` 直接保存到 `TencentCloudClient.fetchImpl`，随后以 `this.fetchImpl(...)` 的形式调用。workerd 会把客户端实例作为函数接收者，而运行时全局 `fetch` 要求正确的全局接收者，因此抛出 `Illegal invocation`。

注入测试使用普通 JavaScript 函数，不检查接收者，导致 M1.17a 的 552 项测试全部通过但没有发现生产差异。项目中 Tripo 与 Hi3D 客户端已有相同问题的绑定保护，新混元客户端未同步复用。

## 修复内容

- 默认运行时请求函数改为 `fetch.bind(globalThis)`；
- 测试注入的 `fetchImpl` 保持原样，既不改变现有测试，也不影响依赖注入；
- 新增 Worker 接收者回归测试，明确断言全局 `fetch` 不能以腾讯云客户端实例作为 `this`；
- 产品可见版本标识更新为 `M1.17a.1`，便于区分生产旧包与热修复候选包；
- 保存用户生产失败截图和本地候选版截图。
