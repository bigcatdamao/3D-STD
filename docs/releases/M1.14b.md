## 用户价值

用户不再从一句需求直接跳到不可控的生图结果。确认 Brief 后，Agent 会先给出三套真正有差异的视觉方向，让用户比较轮廓、构图、材质、打印倾向与取舍，再决定采用哪套方案。

## 本版功能

- Brief 确认后出现独立按钮“生成 3 套视觉方案”；
- 用户点击后才调用一次 LLM 视觉规划，不自动调用图像或 3D 生成；
- 返回三套结构化方案：标题、定位、关键词、描述、优势、取舍和打印倾向；
- 显示 Brief 契合度、辨识度、打印友好度三项相对评分；
- Agent 可以推荐一套，但不会替用户选择；
- 用户选择后必须再次点击“确认选用此方案”；
- 修改 Brief 会自动废弃旧视觉方案和确认状态；
- 视觉方案失败时不生成本地假方案，并返还独立额度；
- 已保存的会话可跨刷新恢复方案、选择和确认状态。

## 技术实现

- 新增 `POST /api/agent/creation/concepts`；
- 新增 `creation-concept-input.v1` 和严格 `creation-concept-output.v1` Schema；
- 输出必须恰好等于请求的 2 或 3 套方案，方案 ID 唯一，推荐 ID 必须真实存在；
- Provider、模型与服务端 Secret 沿用创作 Agent 安全通道；
- 使用独立 `creation-concepts` 配额作用域，默认每访客 5 次/日、单次 2 units；
- 上游超时、拒绝、坏输出和服务异常均退款；
- 未来 `imagePrompt`/`negativePrompt` 只作为数据保存，本版没有任何执行权限。

## 明确不包含

- 不生成效果图或三视图；
- 不展示假图片占位冒充模型结果；
- 不自动选择推荐方案；
- 不调用 Hi3D 或修改模型；
- “打印友好度”只是 LLM 设计倾向评分，不替代真实几何打印检查。
