## 产品结果

M1.9.0 把 M1.7.8 的实验性表面临时预览升级成用户可以实际完成的拆件流程，但没有把它包装成无限制的“智能自动拆件”。用户仍然掌握对象、方向、区域、偏好、预览和最终确认。

- “✂ 拆件”右栏可在“平面切割 / 曲面切割”之间显式切换。
- 移动完全由画布 XYZ 手柄完成；右栏只负责精确旋转、宽高联动大小、表面吸附范围和接缝偏好。
- 曲面预览显示真实蓝色 A 件、紫色 B 件和浅黄色公共接缝；源对象在确认前不变。
- 只有闭环、封口和拓扑验证通过后才允许确认；失败不创建历史或派生资产。
- 确认后生成两个独立派生模型；历史只记录一次曲面切割，可一步撤销和重做。

## 几何实现

- 导向由世界位置与任意世界法向描述；进入 Worker 前转换到源资产局部空间，因此对象旋转和非等比缩放不会把搜索重新锁回世界轴。
- 在焊接后的面邻接图上执行 s-t 最小割；代价综合边长、距导向面距离、相邻面折角和局部三角形密度。
- 支持“均衡 / 最短 / 贴折痕”三种确定性权重，不调用大模型、不消耗 API 额度。
- 输出必须形成一个无分叉、无重复的闭合接缝；多环、分叉、开放链、空零件或不连通结果全部拒绝。
- 封口以 Newell 法线建立二维投影，先验证轮廓不自交和最大扭曲比例不超过 12%，再用 `THREE.ShapeUtils.triangulateShape` 生成 A/B 相反绕序封口。
- 封口后重新计算拓扑边计数；A/B 任何一侧开放边不为 0 都不允许进入确认态。

## 场景、预览与历史

- `previewManualSurfaceSplit` 只运行 Worker 并保存临时 A/B 几何、接缝和指标，不注册场景资产。
- `ManualSurfaceCutPreview` 读取临时结果并使用源实例 TRS 渲染蓝/紫两件；`SceneInstances` 只把源实例降为背景上下文。
- 预览成功时隐藏大面积导向平面，保留 XYZ 操作手柄和真实切口；任何位置、旋转、大小、吸附范围或偏好变化都会使旧预览失效。
- `confirmManualSurfaceSplit` 使用同一份已验证结果注册 A/B 派生资产和实例，并通过 `splitInstanceWithDerivedParts` 写入一条原子历史。
- 撤销同时删除 A/B 派生资产并恢复源实例；重做恢复 A/B。原始几何和原始资产不被原位修改。

## 当前能力边界

- 只接受单个连通、水密、流形的三角网格；源模型已有开放边、多壳、非流形或明显退化面时 fail-closed。
- 当前最多 80,000 个源面，封口轮廓最多 4,096 点；没有高面数代理网格或局部增量重算。
- 接缝沿已有网格边，不是用户自由绘制样条；低模会受到原拓扑分辨率限制。
- 当前只允许一个无分叉闭环；不支持多环、分叉路径或同时拆成三件以上。
- 封口要求接缝近似可投影到平面且扭曲比例不超过 12%；高凹、高扭曲非平面接口会被拒绝，而不是生成可能自交的封口。
- 结果重算法线，只保证几何闭合；不保证 UV、切线、顶点色、蒙皮、变形目标、多材质组或纹理连续性。
- 不包含榫卯、定位销、卡扣、公差、合并、结构强度、装配干涉或最终可制造性验证。
- 这是用户直接操作的确定性本地能力，不向 Agent 开放写权限，也不代表高度自主拆件已经实现。

## 下一步建议

1. 建立角色躯干/四肢、机械装甲、有机件和低模各 3–5 个真实样本的曲面切割验收表。
2. 统计成功率、拒绝原因、接缝长度、封口扭曲、计算耗时和人工可用性，决定先做高模代理还是局部重网格。
3. 若产品目标是示意图那类自由选线，应另立“手绘接缝 + 表面吸附 + 局部重网格 + 非平面封口”任务，不在现有最小割上无限叠加。
4. 榫卯、公差和装配验证继续作为后续独立设计，不与本版基础切割耦合。
