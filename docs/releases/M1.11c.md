## 本版目标

M1.11c 把 M1.11a 的涂画意图和 M1.11b 的绿色闭环接到真实几何能力：

- 紫色面组明确生成“拆下件 A”；
- 未涂区域明确生成“保留件 B”；
- A/B 共用同一条绿色闭环和同一组三角化封口；
- 生成真实预览时不修改源模型；
- 用户确认后才创建两个派生对象，并只写入一条可撤销历史。

## 用户流程

1. 在模型表面涂出要拆下的紫色面组；
2. 点击“生成接缝预览”，通过唯一闭环验证；
3. 点击“生成真实 A/B 预览”；
4. 计算中右栏显示当前阶段，源模型保持不变；
5. 视口显示紫色拆下件 A、绿色保留件 B 和青绿色共享接缝；
6. 右栏核对两件面数、封口面数、尺寸、开放边、封口偏差和扭曲比；
7. 可“返回接缝”继续检查或修改；只有点击“确认创建两个模型”才替换当前实例；
8. 确认后历史增加一条“面组曲面切割”，撤销恢复原实例。

## 几何与数据一致性

- `faceLabels` 使用 `Uint8Array`：`1` 表示紫色拆下件，`0` 表示保留区域。
- BVH 会重排三角面，因此 Worker 输入直接复制画笔会话注册的同一份拾取几何；不再回到原始 STL 面序解释掩码。
- 面组标签在每轮 Worker 请求前复制，Transferable 不会 detach 当前编辑会话的原数组。
- 面组模式绕过旧版平面/曲线最小割，不重新猜测用户意图；已验证闭环直接成为 A/B 分界。
- 源模型必须是单一连通水密流形；退化面、开放边、非流形、多环、分叉、自交或封口失败继续 fail-closed。
- A/B 使用相反绕序的同一组三角化封口；两侧输出后重新统计拓扑开放边，任一侧不为 0 就拒绝进入真实预览。

## 预览、确认与撤销

- `previewing` 只在 Worker 中复制和计算临时几何，不写 `SceneDocument` 或历史。
- `previewReady` 只渲染临时 A/B；源实例降低透明度但仍保留。
- “返回接缝”清除临时 A/B，保留紫色面组和已验证闭环。
- 确认后使用既有 `splitInstanceWithDerivedParts` copy-on-write 命令原子创建两个派生资产和实例。
- 派生资产名称明确为 `A 拆下件`、`B 保留件`，元数据 `kind` 为 `face_set_surface_cut`。
- 一步撤销恢复源实例并移除派生对象；原始资产副本始终没有被覆盖。

## 当前能力边界

- 接缝严格沿现有三角网格边，不包含自由曲线重采样或局部重网格；低面数模型的切口精度受拓扑分辨率限制。
- 封口仍要求闭环能投影为简单二维多边形，并受最大扭曲比限制；强弯曲、折返或自交闭环会拒绝切割。
- 当前只支持一个紫色面组、一个闭环、两个输出零件和单一连通水密源网格。
- 面组边界拓扑预算仍为 100,000 面；真实曲面切割内核预算仍为 80,000 面。
- 只重算法线；不保留 UV、切线、蒙皮、材质组或骨骼关系。
- 不包含榫卯、公差、连接方式、结构强度、装配验证、多环切割、自动拆件或 Agent 写权限。

## 手动验收建议

1. 打开 `http://127.0.0.1:5174/?qa=manual-surface-cut`；
2. 涂出紫色面组并生成绿色闭环；
3. 点击“生成真实 A/B 预览”，确认视口语义为“紫 A 拆下、绿 B 保留”；
4. 点击“返回接缝”，确认面组和闭环仍在、场景树与历史不变；
5. 再次生成预览并确认，检查场景树出现两个独立对象；
6. 在历史中撤销，确认原对象恢复且两个派生对象消失；
7. 使用一个明显非平面或复杂闭环测试 fail-closed 提示，确认失败不会修改源模型。
