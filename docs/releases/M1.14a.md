## 为什么做

旧“文字生成”把提示词输入直接连接到模型生成，既缺少需求澄清，也不适配当前 Hi3D 只支持图片输入的能力。M1.14a 将文字入口升级为“3D 创作 Agent”，让用户先得到可检查的创作需求，再决定是否进入付费生成。

## 本版功能

- 空场景默认打开“3D 创作 Agent”，旧文字直提交通道不再出现在快速生成入口；
- 支持自然语言描述、三个起始示例和连续对话；
- Agent 每轮最多提出 3 个动态多选问题，不重复追问已确认信息；
- 右侧实时生成可编辑 Brief：对象、类型、用途、风格、尺寸和姿态；
- 用户必须显式点击“确认创作需求”，确认前后均不调用生图或 3D 生成；
- AI 服务不可用时进入明确标注的本地引导；
- 对话与 Brief 可在刷新后恢复，也可一键重新开始；
- 原单图/多图 Hi3D 入口保留为“快速图生模型”。

## 技术实现

- 新增 `POST /api/agent/creation`；
- 使用 Responses API、`store:false` 和严格 JSON Schema；
- Provider 只允许 OpenAI 或 AIHubMix，Key 只从 Cloudflare Worker Secret 读取；
- 创作 Agent 使用独立配额/熔断作用域，上游失败自动返还；
- 本地规则只用于离线降级，并在 UI 中显示来源；
- 新增结构化输入输出类型、解析校验和单元测试。

## 明确不包含

- 不自动生成效果图或三视图；
- 不自动调用 Hi3D；
- 不调用拆件、榫卯、修复或排盘工具；
- 不把 Brief 确认等同于整条链路授权；
- 不上传参考图（本版只预留数量字段）。
