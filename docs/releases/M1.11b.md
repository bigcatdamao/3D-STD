## 本版目标

M1.11b 只回答两个问题：

1. 用户涂出的面组边界是不是一条可解释的唯一闭环；
2. 在真正切割前，程序能否把明显的拓扑和封口风险明确暴露出来。

本版不执行真实切割。“M1.11c：确认切割”保持禁用，避免把只读边界分析伪装成已经完成的 A/B 网格能力。

## 用户流程

1. 使用 M1.11a 画笔涂出紫色面组；
2. 黄色边界形成后点击“生成接缝预览”；
3. 验证失败时继续留在画笔态，右栏列出断环、分叉、多环、开放边或非流形原因；
4. 验证通过时画笔冻结，视口显示 4px 绿色闭环；
5. 用户可旋转、平移、缩放检查接缝，并读取长度、顶点数、平面偏差、A/B 面数占比；
6. 点击“返回修改面组”恢复画笔；不修改模型，也不写场景历史。

## 接缝验证

- 面组掩码、边界和接缝统一绑定 BVH 重排后的同一份拾取几何，避免原始面序与画笔面序错位。
- 焊接拓扑为每个端点保存稳定 ID；边界图以顶点度数检测断点（度 1）和分叉（度 > 2）。
- 边界图按连通分量检测多个独立环；当前每次只允许一个闭环。
- 面组触及源网格开放边或非流形边时拒绝通过，并提示先做水密/拓扑修复。
- 唯一闭环按邻接关系排序；退化闭环和二维投影自相交继续拒绝。
- 超过 100,000 面维持流畅降级：只显示紫色面组，不构建焊接边图和接缝。

## 风险指标

- 接缝长度：按实例位置、旋转和缩放后的世界毫米计算。
- 平面偏差：用 Newell 法线和闭环质心计算最大点到平面的偏离。
- 过薄风险：根据已涂区域世界包围盒的最小尺寸提示。
- 极小件风险：根据 A/B 两侧三角面占比提示。
- 非平面、过薄和极小件目前只给 warning；M1.11c 在执行真实切割前必须再次验证真实封口与 A/B 网格。

## 状态和权限

- 接缝预览只存在于当前临时面组会话。
- 进入只读态后禁止新画笔笔划；右键旋转、中键平移和滚轮缩放仍可使用。
- “返回修改面组”只清空临时接缝结果；已涂面组和笔划撤销栈保留。
- 只读态 `Ctrl+Z` 等价于返回修改面组；编辑态 `Ctrl+Z` 仍撤销上一笔。
- 不创建派生资产，不替换实例，不持久化，不写场景历史，不覆盖源模型。

## 当前能力边界

- 接缝仍沿面组三角形边界，不是经过局部重网格后的自由曲线。
- 面数占比只用于早期风险提示，不等于两个真实封闭零件的体积占比。
- 平面偏差用于封口风险判断，不会在本版生成平面或曲面封口。
- 对强弯曲闭环、细长薄壳和复杂自交，M1.11c 真实切割仍可能 fail-closed。
- 不包含 A/B 切割、封口、榫卯、公差、装配验证、骨骼识别或 Agent 写权限。

## 下一步

M1.11c 只有在本版视觉验收通过后才开始：把已验证的唯一闭环提交给真实几何内核，先生成 A/B 临时网格和封口结果，再由用户确认写入一条可撤销历史。
