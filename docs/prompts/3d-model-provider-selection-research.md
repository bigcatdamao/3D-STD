## 项目背景

当前作品集主链路是：

1. 用户已有图片 → 图生 3D；
2. 用户输入模糊需求 → 3D 创作 Agent 对话澄清 → 效果图/多视图 → 3D 模型；
3. 模型自动拆件；
4. 添加榫卯、设置公差并检查装配；
5. 检查水密、薄壁、悬空等打印问题；
6. 导出 STL，交给切片软件。

当前已经接入：

- DeepSeek V4 Flash：自然语言需求澄清；
- Gemini 2.5 Flash：参考图理解；
- GPT 系列模型：结构化视觉方案与效果图；
- 腾讯混元 3D 3.1：图生/多视图生 3D；
- 腾讯混元组件生成：自动拆件候选；
- Hi3D：曾用于模型生成和自动拆件，但出现提交失败、生成细节不足和拆件后细节损失等 bad case。

当前技术矛盾是：

- 网页预览与编辑更适合 GLB；
- 混元组件生成当前要求 FBX；
- 用户常见本地文件可能是 STL、OBJ 或 GLB；
- 最终打印交付通常需要 STL 或 3MF；
- 通用转换会引入 COS/R2、签名 URL、单位、法线、拓扑、文件过期和清理等工程问题。

当前产品是为了投递 3D 打印 AI 产品经理岗位的作品集 Demo，不是立即商业化。请控制方案量级，不要默认要求建设完整 SaaS 基础设施。

1. 必须查阅截至当前日期的官方文档、API 文档、计费页和格式说明，并附直接链接。

3. 对每个供应商核实：

   - 是否返回 GLB、FBX、OBJ、STL、3MF；
